🏥 AI-Powered Multi-Disease Prediction System

Overview

This project is a Machine Learning-based web application that predicts the risk of multiple diseases, including Diabetes, Heart Disease, Liver Disease, and Kidney Disease. Users enter health parameters, and the system provides instant predictions.

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Streamlit
- Joblib

Features

- Diabetes Prediction
- Heart Disease Prediction
- Liver Disease Prediction
- Kidney Disease Prediction
- User-Friendly Interface
- Real-Time Results

How to Run

pip install -r requirements.txt
streamlit run app.py

Workflow

User Input → Data Processing → ML Model → Prediction → Result

Conclusion

This project demonstrates the use of Machine Learning in healthcare for early disease prediction and health risk assessment.
